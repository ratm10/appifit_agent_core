Android APK 자가 업데이트의 다운로드·설치 기계. 버전 JSON 비교로 신규 유무를 판정하고, flutter_downloader 큐를 0.5s로 폴링하며 완료 시 app_installer로 설치를 띄운다. 버전 JSON·다운로드 URL은 소비자 앱이 주입(채널 분기는 앱 몫).
플랫폼 — 저장 경로는 Android ApplicationSupportDirectory / 기타 TemporaryDirectory. 일부 기기가 complete를 미보고해도 running 100%가 4회 연속이거나 태스크 소멸 시 완료로 간주(강건성). Windows OTA(ZIP·updater.bat)는 이 패키지가 아니라 소비자 앱 측 구현.
